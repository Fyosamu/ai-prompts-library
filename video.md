## 1. First 15 Seconds (10 Variants)

```text
Write 10 opening hooks for a YouTube video about [TOPIC] for
[AUDIENCE].
Each must be SPOKEN in under 15 seconds (about 40 words).
Mix: bold claim, question, result reveal, story cold-open,
negative warning, pattern interrupt.
No "Hey guys, welcome back to my channel."
```

## 2. Cold Open Reveal

```text
Write a 20-second cold open for a video about [TOPIC] that starts
mid-action or mid-result, then rewinds to explain.
Spoken language, under 55 words, ends on a line that demands the
next 30 seconds.
```

## 3. Contrarian Hook

```text
Write 8 contrarian opening lines for [TOPIC].
Each states a popular belief then immediately challenges it with
one specific reason. Under 30 words. Spoken, not written.
```

## 4. Result-First Hook

```text
Write 6 openings that lead with a concrete result:
"I [did X] and got [specific number]" - then tease the method.
Each under 35 words. Must be honest and plausible.
```

## 5. Question Hook Ladder

```text
Write a 3-question opening for [TOPIC] where each question goes
deeper and the last one can only be answered by watching.
Under 45 words total. Spoken style.
```

## 6. Stakes Hook

```text
Write 7 opening lines for [TOPIC] that make the cost of not
watching concrete and specific (time, money, mistakes).
Each under 30 words. No fear-mongering - be accurate.
```

## 7. Story Cold Open

```text
Write a 30-second cold open story about [EXPERIENCE] for [TOPIC].
- Open mid-action, no context yet
- One concrete detail (number, place, time)
- Cut off right before the lesson
- Under 80 words, spoken
```

## 8. Hook Bank For A Series

```text
Give me 20 reusable opening formats for a channel about [NICHE],
written as fill-in templates with a worked example for each.
```

## 9. Explainer Video (8 Minutes)

```text
Write a full script for an 8-minute explainer on [TOPIC].
Target: about 1,100 spoken words.
Structure with timestamps:
- 0:00 hook (under 15 seconds)
- 0:15 why it matters
- 0:45 3 main sections with a mini-payoff at each
- 6:30 summary
- 7:00 call to action
Mark B-ROLL ideas in [brackets]. Use short sentences.
```

## 10. Listicle (top 7)

```text
Write a "Top 7" script about [TOPIC].
- Hook under 15 seconds that names the number and payoff
- Each item: name it, why, one concrete example
- Build so #1 is genuinely the best
- Recap + CTA
About 900 words. One transition line between items.
```

## 11. How-To Tutorial

```text
Write a step-by-step tutorial script for [SKILL/TASK].
- Hook: the outcome in one sentence
- Prerequisites in one line
- Steps numbered, each with what to do AND the mistake to avoid
- Common problems section
- Result + CTA
About 1,000 words. Written to be spoken.
```

## 12. Story / Documentary Style

```text
Write an 12-minute documentary-style script about [SUBJECT].
- Cold open
- Context and stakes
- 3 acts with rising tension
- Twist or turning point
- Resolution and meaning
About 1,600 words. Note archival footage and [B-ROLL] cues.
```

## 13. Vlog / Personal Story

```text
Write a vlog script about [EXPERIENCE] connected to [TOPIC].
Conversational, natural digressions, one honest vulnerability,
one lesson. About 700 words. Mark where a cut or scene change
should happen with [CUT].
```

## 14. Commentary / Reaction

```text
Write a commentary script reacting to [CLIP / NEWS / TREND].
- State your position in the first 15 seconds
- Reference specific moments
- Steelman the other side once
- Land on a clear opinion
About 800 words.
```

## 15. Video Essay (15 Minutes)

```text
Write a 15-minute video essay script on [TOPIC].
- Thematic cold open
- A question the video will answer
- 4 developing sections with evidence
- A reframe near the 2/3 point
- Payoff that ties back to the opening
About 2,000 words. Literary but spoken - no academic throat-clearing.
```

## 16. Interview Questions (15)

```text
Write 15 interview questions for a guest who [EXPERTISE].
Order them: easy warm-up -&gt; specific stories -&gt; contrarian
provocation -&gt; closing reflection.
For each, add one likely follow-up. Avoid yes/no phrasing.
```

## 17. Unboxing / First Impressions

```text
Write an unboxing script for [PRODUCT].
- Hook: what you're hoping it delivers
- Unboxing with genuine reaction beats
- 3 things you notice that specs don't show
- First honest verdict
About 600 words.
```

## 18. Challenge / Experiment

```text
Write a challenge video script: "[I did X for Y days]".
- Before state and the bet
- Day-by-day escalation with a low point
- The result (honest, including if it failed)
- What you'd do differently
About 900 words.
```
