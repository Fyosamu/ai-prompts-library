## 1. Etsy Title (140 Char)

```text
Write 10 Etsy titles for [PRODUCT] targeting [BUYER].
Rules:
- Maximum 140 characters each
- Front-load the highest-volume keyword in the first 5 words
- Separate phrases with commas
- Natural and readable, not keyword soup
- Include: material, use case, style, and who it's for
Show the character count after each.
```

## 2. Title A/B Variants

```text
Write 5 title variants for [PRODUCT] each built around a
DIFFERENT search intent:
(a) what it is, (b) who it's for, (c) the occasion,
(d) the style, (e) the problem it solves.
Under 140 chars each. Label the intent.
```

## 3. Keyword-First Title

```text
Here is my product: [DESCRIPTION]
Here are the top Etsy search phrases: [KEYWORD LIST]
Write 8 titles that work as search phrases a real buyer would
type, in that buyer's actual words. Under 140 chars.
No all caps. No repeat of the same word twice in a row.
```

## 4. Amazon Title (200 Char)

```text
Write 5 Amazon product titles for [PRODUCT] in [CATEGORY].
Format: Brand + Product Type + Key Feature + Size/Quantity.
Max 200 characters. Put the most important keyword first.
No promotional phrases ("best", "#1") - Amazon penalizes them.
```

## 5. Shopify Collection Title

```text
Write 10 collection/category page titles for a store selling
[PRODUCTS] to [AUDIENCE].
Each under 8 words, keyword-rich but human, no generic names
like "Products" or "Shop All".
```

## 6. Gift Guide Title

```text
Write 8 gift-guide style titles for [PRODUCT] aimed at
[OCCASION] shoppers.
Each must signal who it's for: "Gifts for [WHO]".
Under 10 words. Under 140 chars.
```

## 7. Title Health Check

```text
Audit this product title:
[PASTE TITLE]
Score 1-10 on: primary keyword placement, readability, character
count, specificity, and click appeal. Then rewrite 3 stronger
versions. Be blunt about what's wrong.
```

## 8. Bundle Title

```text
Write 6 titles for a bundle of [ITEMS] that makes the value
obvious - include the count and the savings.
Under 140 chars. The number must appear near the start.
```

## 9. Etsy Description (full)

```text
Write a complete Etsy description for [PRODUCT].
Structure:
- Line 1-2: hook that names the buyer's goal (visible before
  "read more")
- WHAT YOU GET: bullet list
- WHO IT'S FOR: 3 bullets
- HOW IT WORKS: 3 steps
- FILE / SPEC details
- FAQ: 4 questions
- Closing CTA
Plain language. No emoji walls. Under 600 words.
```

## 10. Benefit-First Description

```text
Rewrite this feature list as benefits:
[PASTE FEATURES]
Target buyer: [AUDIENCE]
Format each as: "You get [FEATURE] so you can [OUTCOME]."
10 bullets max. Cut anything that isn't a real benefit.
```

## 11. Short Mobile Description

```text
Write a 120-word product description for [PRODUCT].
Assume it's read on a phone. Short paragraphs, one idea each,
no jargon, first line must sell the outcome.
```

## 12. Description Without Hyperbolic Filler

```text
Write a product description for [PRODUCT] with these rules:
- No: amazing, incredible, revolutionary, game-changing,
  must-have, elevate, unleash, seamless
- Concrete over abstract - every claim needs a number or detail
- Honest about limitations
- Under 250 words
```

## 13. Digital Product Description

```text
Write a description for a digital download [PRODUCT].
Must clearly state: format, file count, compatibility, delivery
(instant), that it's non-refundable (digital goods), and how to
access it after purchase. Under 400 words.
```

## 14. Physical Product Description

```text
Write a description for a physical [PRODUCT].
Include: materials, dimensions, weight, care instructions,
shipping window, and handmade/production notes.
Under 350 words. Accurate and reassuring.
```

## 15. Luxury / Premium Description

```text
Write a premium-tone description for [PRODUCT] at [PRICE].
Understated confidence, sensory specifics, craftsmanship detail.
No exclamation marks. Never say "premium" or "luxury" directly.
Under 300 words.
```

## 16. Problem-Agitation Description

```text
Write a description that opens by naming a specific frustration
[BUDIENCE] has with [OLD SOLUTION], then introduces [PRODUCT] as
the fix, then lists proof. Under 350 words. Empathetic, not
salesy.
```

## 17. Etsy 13 Tags

```text
Give me exactly 13 Etsy tags for [PRODUCT].
Rules:
- Each tag maximum 20 characters
- Use multi-word phrases (they match more searches than singles)
- No repetition of the same word across tags
- Mix: broad, specific, occasion, style, gift-buyer
- Plain words buyers actually type
List as 13 separate items.
```

## 18. Tag Set By Intent

```text
Build 13 Etsy tags for [PRODUCT] split across 4 intents:
- 4 broad category tags
- 4 specific/long-tail tags
- 3 occasion/gift tags
- 2 style/aesthetic tags
All under 20 characters.
```
