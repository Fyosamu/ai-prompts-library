01 Etsy Title (140 Char)



```text
Write 10 Etsy titles for [PRODUCT] targeting [BUYER].
Rules:
- Maximum 140 characters each
- Front-load the highest-volume keyword in the first 5 words
- Separate phrases with commas
- Natural and readable, not keyword soup
- Include: material, use case, style, and who it's for
Show the character count after each.
```

02 Title A/B Variants



```text
Write 5 title variants for [PRODUCT] each built around a
DIFFERENT search intent:
(a) what it is, (b) who it's for, (c) the occasion,
(d) the style, (e) the problem it solves.
Under 140 chars each. Label the intent.
```

03 Keyword-First Title



```text
Here is my product: [DESCRIPTION]
Here are the top Etsy search phrases: [KEYWORD LIST]
Write 8 titles that work as search phrases a real buyer would
type, in that buyer's actual words. Under 140 chars.
No all caps. No repeat of the same word twice in a row.
```

04 Amazon Title (200 Char)



```text
Write 5 Amazon product titles for [PRODUCT] in [CATEGORY].
Format: Brand + Product Type + Key Feature + Size/Quantity.
Max 200 characters. Put the most important keyword first.
No promotional phrases ("best", "#1") - Amazon penalizes them.
```

Write 10 collection/category page titles for a store selling

```text
Write a complete Etsy description for [PRODUCT].

- WHO IT'S FOR: 3 bullets

- FILE / SPEC details
- FAQ: 4 questions
- Closing CTA
Plain language. No emoji walls. Under 600 words.
```
